# 🤖 Идея-бот для Telegram

Личный ассистент для записи идей, голосовых заметок и еженедельной сводки.

## Что умеет
- 🎤 Расшифровывает голосовые сообщения (Groq Whisper)
- 💡 Сохраняет идеи, текст и ссылки
- 🧠 Автоматически определяет тему (Gemini AI)
- 📊 Каждую пятницу в 18:00 присылает сводку недели с чеклистом
- ⚡ Геймификация: XP и уровни за выполненные задачи

---

## Шаг 1: Получи ключи (всё бесплатно)

### Telegram Bot Token
1. Открой @BotFather в Telegram
2. Напиши `/newbot`
3. Придумай имя (например: `Мои Идеи`) и username (например: `my_ideas_bot`)
4. Скопируй токен вида `123456789:ABCdef...`

### Groq API Key (для расшифровки голоса)
1. Зайди на https://console.groq.com
2. Sign Up (можно через Google)
3. Слева → API Keys → Create API Key
4. Скопируй ключ

### Gemini API Key (для ИИ-анализа)
1. Зайди на https://aistudio.google.com
2. Войди через Google аккаунт
3. Нажми "Get API Key" → "Create API key"
4. Скопируй ключ

---

## Шаг 2: Залей код на GitHub

1. Зайди на https://github.com и создай аккаунт (если нет)
2. Создай новый репозиторий: New repository → назови `idea-bot` → Create
3. Залей файлы:
   - Нажми "uploading an existing file"
   - Перетащи все файлы из папки `idea-bot`
   - Commit changes

---

## Шаг 3: Задеплой на Koyeb (бесплатно)

1. Зайди на https://app.koyeb.com
2. Sign Up через GitHub
3. Нажми **Create App** → **GitHub**
4. Выбери репозиторий `idea-bot`
5. Настройки:
   - **Run command**: `python bot.py`
   - **Instance type**: Free
6. Добавь переменные окружения (Environment Variables):
   ```
   BOT_TOKEN = твой_токен_от_BotFather
   GROQ_API_KEY = твой_ключ_от_Groq
   GEMINI_API_KEY = твой_ключ_от_Gemini
   ```
7. Нажми **Deploy**

Через 2-3 минуты бот будет онлайн 🎉

## Команды бота

| Команда | Что делает |
|---------|-----------|
| `/start` | Запуск и инструкция |
| `/list` | Все идеи за неделю |
| `/summary` | Сводка прямо сейчас |
| `/done 3` | Отметить идею №3 выполненной |
| `/stats` | Твой уровень и XP |

---

## Как пользоваться

- **Голосовое** → просто надиктуй, бот сам расшифрует и сохранит
- **Текст** → напиши что угодно
- **Ссылка** → просто скинь URL, сохранится с темой

Каждую **пятницу в 18:00** придёт сводка с чеклистом на выходные.
Каждый **понедельник в 9:00** — мотивационное напоминание.

(Время по Павлодару, UTC+5)
